Found nebula-cert executable binary file.

Could not find nebula-cert executable file. Pulsar will function without the nebula-cert executable. However, Pulsar will not be able to determine the validity of the connection authentication certificates or the IP address of your node. To rectify this, make sure the nebula-cert executable file is in the same directory as the nebula executable file.
