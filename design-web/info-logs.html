Pulsar :: A GUI Wrapper for Nebula

Pulsar is a cross-platform, graphical user interface wrapper for Slack’s Nebula command line client, which was developed to make it easier for non-technical users to connect to a Nebula mesh network. Like a pulsar inside a nebula, it sends out a regular pulse to make the connection possible. While it is best used for connecting to a single Nebula mesh network, Pulsar has the capability to connect to up to five networks simultaneously, provided the networks have differing IP address ranges. It makes setting up the connections easy through the Settings page.

For security, Pulsar does not provide the Nebula command line executable file. The user needs to download and install it themselves and either add it to the system path or else point Nebula to the executable file. Because Nebula opens a special encrypted tunnel to the mesh network, the executable requires administrative privileges. The request dialog for these privileges will be triggered when the Connect button is clicked. It will trigger separately for each connection, so if you have multiple connections, you will see multiple privilege elevation dialogues.
